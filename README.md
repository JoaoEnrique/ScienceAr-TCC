# 🌌 Science AR

Aplicativo educacional de **Ciências da Natureza** com uso de **Realidade Aumentada (AR)**, desenvolvido para alunos do 7º ano.  
O objetivo do projeto é tornar o aprendizado mais **interativo**, **imersivo** e **divertido**, aproximando a ciência da realidade dos estudantes.  

---

## ✨ Funcionalidades

- 📱 Visualização de **modelos 3D em realidade aumentada** (animais, plantas, objetos e fenômenos naturais).
- 🔍 Conteúdos interativos sobre Ciências da Natureza.
- 🎓 Ferramenta de apoio pedagógico para professores.
- 🖼️ Interface amigável e acessível.
- 🔗 Integração com a web para consulta rápida.

---
